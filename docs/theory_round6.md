## 0. 设定与"规范变换"的含义

列向量记号。残差流 x_l ∈ ℝ^d（l = 0 … L），x_0 = E[token] (+ P[pos])，x_{l+1} = x_l + （本层写入）。
读取函数记为 n：
- RMSNorm：n(x) = x / √(‖x‖²/d + ε)；
- LayerNorm：n(x) = Px / √(‖Px‖²/d + ε)，P = I − 11ᵀ/d。

norm 的增益 γ 与 LN 的偏置 β 总可以折进其后的线性映射（W(γ⊙n + β) + b = (W diag γ) n + (Wβ + b)），下文假定已折叠。

**规范变换**（本文的对象）：一个可逆线性映射 A，使得存在同一结构的另一组权重，令新网络在**每一层**都满足 x′_l = A x_l，且 logits 不变。
写入都是线性的（嵌入行、注意力输出与 MLP 输出的权重和偏置），总能用 W ↦ AW 吸收；所以约束全部来自**读取**。

**"结构上的"规范群**：要求同一个 A 对**任意参数取值**都可吸收。这样 E 可以是任意矩阵，x_0 取遍 ℝ^d 的开集，下面的必要性论证才成立。
对某一个具体的训练好的模型，群可能更大（例如增益恰好有相同的值），这里给的是对一般参数成立的群。

引理 0（解析延拓）。n 在 ℝ^d 上实解析（ε > 0）。若 n(Ax) = B n(x) 在某个开集上成立，则在全 ℝ^d 上成立。

## 命题 1：final norm 之后，表示只确定到仿射群

h = γ⊙n(x) + β 之后只有线性读出 z = W h + b。对任意可逆 A 与平移 c，h′ = Ah + c、W′ = WA⁻¹、b′ = b − WA⁻¹c 给出同一 z。
读出不经过任何非线性，所以没有更多约束：群是 GL(d) ⋉ ℝ^d。这是阶段一的规范群；"V3 = diag(γ)V1 + β"本身就是其中的一个元素。

## 命题 2：残差流（pre-norm）

**(a) RMSNorm、ε > 0：群恰为 O(d)。**

- 充分性：‖Qx‖ = ‖x‖，所以 n(Qx) = Q n(x)；读取 W ↦ WQᵀ，写入 W ↦ QW，头 W_U ↦ W_U Qᵀ。这是 SliceGPT（Ashkboos et al. 2024，Theorem 1）的"computational invariance"。
- 必要性：取一个列满秩的读取矩阵 W（注意力的 q/k/v 拼接为 3d × d，MLP 输入为 ≥ 4d × d，都可以列满秩）。W′ n(Ax) = W n(x) 对所有 x 成立，
  左乘 W 的伪逆得 n(x) = M n(Ax)，即 n(Ax) = B n(x)，B = M⁻¹（M 必可逆，否则 n(x) 的像落在真子空间里）。由引理 0 在全空间成立。
  在 x → 0 处展开：n(x) = x/√ε + O(‖x‖³)，比较一阶项得 B = A。代回：Ax/√(‖Ax‖²/d + ε) = Ax/√(‖x‖²/d + ε)，所以对所有 x 有 ‖Ax‖ = ‖x‖，A 正交。∎
- ε = 0 时，一阶展开不可用，同样的论证给出 A = λQ（λ > 0），即多一个整体缩放。

**(b) LayerNorm、ε > 0：群为 G_LN = { A : A1 = c1（c ≠ 0），且 PAP 在 1⊥ 上是正交变换 }。**

在基 (1⊥, 1/√d) 下，A = [[Q, 0], [wᵀ, c]]：1⊥ 上的正交 Q，加上沿 1 的任意缩放 c 和"指向 1"的剪切 x ↦ x + (wᵀx)·1/√d。

- 必要性：与 (a) 相同得到 n(Ax) = B n(x) 对全空间成立。取 x = t1，n(x) = 0，所以对所有 t 有 n(tA1) = 0，即 PA1 = 0，A1 = c1。
  一阶展开得 PA = BP；对 x ∈ 1⊥ 同 (a) 的论证得 ‖PAx‖ = ‖x‖。又因为 A 把 span(1) 映到 span(1)，PA = PAP。所以 PAP 是 1⊥ 上的等距，即正交。
- 充分性：对 A ∈ G_LN，PAx = PAPx（沿 1 的部分被 P 去掉），且 ‖PAPx‖ = ‖Px‖，所以 n(Ax) = R n(x)，R = PAP。读取 W ↦ WRᵀ（RᵀR = P，而 n(x) ∈ 1⊥）。∎
- 含义：**残差流沿全 1 方向的分量对任何读取都不可见**。它可以被任意缩放、可以从其他方向"剪切"进来，输出不变。
  任务书预期的"保持全 1 方向的正交变换"只是 G_LN 的子群。SliceGPT 把 LN 模型的均值相减乘进写入矩阵、转换为 RMSNorm，相当于选了 w = 0、把沿 1 的分量置零的一个规范。
  这与 Gupta et al. 2024 的经验观察一致：LN 模型的残差流本来就几乎与 1 正交（那一分量对功能没有作用）。

**(c) 子层输出后 norm（OLMo-2、Olmo-3）：群（一般参数下）为带符号置换。**

结构为 x_{l+1} = x_l + diag(γ_l) n(W_o z)（注意力与 MLP 各一次），读取是线性的、不经过 norm，最后有 final norm。

- final norm 的读取与 (a) 相同，给出 A 正交。
- 写入端：要求 A diag(γ) n(u) = diag(γ′) n(N u) 对所有 u（W_o 一般满秩，u = W_o z 取遍开集）。由 (a) 的引理，N 正交，且 diag(γ′)⁻¹ A diag(γ) = N。
  两边乘转置：A diag(γ²) Aᵀ = diag(γ′²)。对一般的 γ（各分量平方互不相同），对角化矩阵 diag(γ²) 的正交矩阵只能是带符号置换。∎
- 充分性：A = SΠ（S 为 ±1 对角，Π 为置换）时 n(Au) = A n(u)，γ′ = Πγ（不带符号），读取 W ↦ WA⁻¹。
- 对某个具体模型，若各层的 γ 在某些坐标上处处相等，群会多出这些坐标块内的旋转；一般训练好的模型不会。
- 含义：在这类结构里，残差流的坐标基本是确定的（只差符号和重新编号），逐坐标的量（离群维度、massive activation）是函数决定的；
  在 pre-norm 结构里则不是。Olmo-3.1-32B-Instruct 属于这一类。

## 命题 3（推论）：哪些指标是确定的

isotropy A（序列内两两余弦）、中心化 B、RankMe、任意两个 token 的余弦，对作用在**所有 token 上的同一个正交变换**不变（余弦与奇异值不变，中心化与线性映射交换）。所以：

| 位置 | 规范群 | A、B_c、RankMe、余弦 | 逐坐标的量（OD、zscore） |
|---|---|---|---|
| final norm 之后（V3） | GL(d) ⋉ ℝ^d | **不确定**（阶段一 P6-2：κ ≤ 10 的对角变换即可让 66 对模型的区间全部相交） | 不确定 |
| final norm 之前、增益之前（V1 = n(x)），pre-norm RMSNorm | O(d) | 确定 | 不确定（只确定到旋转） |
| 同上，LayerNorm | G_LN，在 n(x) 上作用为 1⊥ 上的 O(d − 1) | 在 n(x) 上确定；**在未归一化 x 上不确定**（剪切） | 不确定 |
| 同上，子层输出后 norm | 带符号置换 | 确定 | 确定（到符号与重新编号） |

- 未归一化的 RMSNorm 残差流 x：群仍是 O(d)，所以 x 上的这些量也确定（余弦与 n(x) 相同）。
- 本项目的 V1 一直定义为 n(x)（final norm 的归一化、增益之前），因此对 12 个模型都处在"确定"的一行。
- "确定"只针对函数意义上的等价。训练过程（如 Adam 的逐坐标归一化）可以让 pre-norm 模型的残差流出现经验上的特权基（Anthropic 2023），
  但哪个基是特权的，不由模型的输出决定。
